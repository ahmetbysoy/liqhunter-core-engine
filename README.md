# Vite React Foundation

Clean Vite + React foundation. Product behavior and visual direction are intentionally not defined yet.

## Structure

- `src/App.jsx`: application entry component
- `src/components/`: shared interface components
- `src/features/`: feature-level modules
- `src/hooks/`: reusable React hooks
- `src/lib/`: non-visual utilities and integrations
- `src/pages/`: route-level screens
- `src/styles/`: global and design-system styles
- `public/`: static assets

## Commands

```bash
npm install
npm run dev
```
